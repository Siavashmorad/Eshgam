# عشقم ❤️ — Eshgam

اپ خصوصی دو نفره برای شما و همسرتان.

## امنیت

- ثبت‌نام عمومی ندارد.
- Pairing با یک راز مشترک انجام می‌شود.
- راز در `flutter_secure_storage` نگهداری می‌شود و به SharedPreferences سپرده نمی‌شود.
- محتوای پیام قبل از ذخیره‌سازی با AES-GCM رمز می‌شود.
- احراز هویت بیومتریک/قفل دستگاه برای ورود استفاده می‌شود.
- معماری برای دو دستگاه مورد اعتماد طراحی شده است.

## نکته مهم درباره نسخه فعلی

این commit «هسته نصب‌شدنی و پایه امنیتی» را فراهم می‌کند و پیام‌ها را به‌صورت محلی رمزنگاری می‌کند. برای تبدیل آن به پیام‌رسان واقعی بین دو گوشی از راه دور، باید یک لایه ارتباطی/Signaling اضافه شود. این لایه نباید کلید خصوصی یا متن رمزگشایی‌شده را ببیند. تماس صوتی/تصویری نیز برای WebRTC به signaling نیاز دارد.

ادعای امنیت ۱۰۰٪ یا غیرقابل‌نفوذ بودن برای هیچ نرم‌افزاری ممکن نیست؛ هدف این پروژه کمینه‌کردن سطح اعتماد و جلوگیری از دسترسی سرور/شخص ثالث به محتوای رمزگشایی‌شده است.
