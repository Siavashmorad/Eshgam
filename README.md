# عشقم ❤️ — Eshgam

پیام‌رسان خصوصی دو نفره برای شما و همسرتان.

## وضعیت معماری

- Pairing فقط با یک رمز مشترک خصوصی انجام می‌شود.
- هر دستگاه یک شناسه تصادفی مستقل دارد.
- Relay برای هر Pair حداکثر دو دستگاه را می‌پذیرد.
- متن پیام روی دستگاه با AES-256-GCM رمز می‌شود و Relay فقط ciphertext می‌بیند.
- پیام‌های محلی نیز به‌صورت رمزنگاری‌شده ذخیره می‌شوند.
- ورود با قفل/بیومتریک سیستم عامل پشتیبانی می‌شود.
- ارتباط realtime با WebSocket روی `wss://` انجام می‌شود.
- `server/` یک Relay قابل self-host است و Docker/Compose دارد.

## اجرای Relay

روی سرور خودتان:

```bash
cd server
docker compose up -d --build
```

برای امنیت واقعی اینترنتی، جلوی سرویس TLS معتبر قرار دهید و فقط `wss://` را به اپ بدهید. فایل `server/data/state.json` فقط شناسه Pair، hash رمز و شناسه دستگاه‌ها را نگه می‌دارد و متن پیام‌ها در آن ذخیره نمی‌شود.

در هر دو گوشی، هنگام Pair کردن، همان رمز خصوصی و همان آدرس Relay را وارد کنید. رمز را هرگز در GitHub یا برای شخص دیگری منتشر نکنید.

## APK

Workflow گیت‌هاب `.github/workflows/android-apk.yml` APK Release را می‌سازد و به‌عنوان artifact منتشر می‌کند.

## تماس صوتی/تصویری

Relay برای signaling قابل استفاده است، اما تماس اینترنتی پایدار WebRTC به ICE/STUN/TURN نیاز دارد. برای مدل «بدون شخص ثالث»، STUN/TURN نیز باید روی زیرساخت تحت کنترل خودتان اجرا شود. تا زمانی که آن زیرساخت و گواهی TLS فراهم نشده، برنامه نباید ادعا کند تماس اینترنتی کاملاً فعال است.

## محدودیت مهم امنیتی

هیچ نرم‌افزاری را نمی‌توان صادقانه ۱۰۰٪ غیرقابل نفوذ تضمین کرد. این پروژه برای کاهش سطح اعتماد طراحی شده است: محتوای پیام قبل از خروج از دستگاه رمز می‌شود و Relay متن رمزگشایی‌شده را دریافت نمی‌کند. برای امنیت سطح تولید، بازبینی مستقل کد و تست نفوذ نیز توصیه می‌شود.
